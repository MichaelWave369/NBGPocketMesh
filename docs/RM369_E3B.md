## Contract

Input is canonical RM1 snapshot bytes. Request contains expected_sha256,
physical path, strategy and integer budget 0..9. A separate fixture grant
contains snapshot_sha256, exact physical path, max_probes, allowed local
cell indices and boolean direct. Both digests must match the snapshot.
A request cannot extend its supplied grant. A denied path, cell,
orientation channel, budget or malformed snapshot throws. The returned
receipt contains the observed local seed digits, compatible D4 candidates,
unique resolution if any, exact consumed probe count, snapshot binding
and canonical SHA-256. Verification replays, not merely checks the digest.

The grant is caller-supplied and unsigned: it does not establish real
identity, authority, revocation or isolation. A local seed digit differs
from a global recursive cell value; the broker has the complete snapshot
and decodes it, so this is not actual partial loading or a privacy barrier.
Budget is a per-request count of declared observations, not a CPU, memory,
network or cumulative privacy budget. Inference from allowed probes may
recover an orientation even when direct lookup is disallowed.

## Exhaustive known-family comparison

Eight orientations, noiseless readings and a known physical frame/seed:

| Strategy | Observations per case | Distinct classes | Uniquely resolved cases |
| --- | ---: | ---: | ---: |
| Center | 1 | 1 | 0/8 |
| Corner | 1 | 4 | 0/8 |
| Corner + adjacent edge | 2 | 8 | 8/8 |
| Full | 9 | 8 | 8/8 |
| Direct orientation lookup | 1 | 8 | 8/8 |

Two cell probes save seven cell observations relative to full read; direct
orientation lookup still wins when available under this unit-cost model.
It is not a claim that the two channels cost the same in real systems.
The paired strategy is fixed, not learned or adaptive. The full snapshot
is hashed and decoded on every request, so observation count is not a
proxy for runtime or actual memory usage.

The cross-language chain is tested pairwise: E3-A compares actual Codex
Python output with Altermath; E3-B imports pinned Altermath and observes
24 transformed snapshots at depths 1, 12 and 64. No joint live deployment.
Regular npm test skips the producer test without the environment variable;
the dedicated CI must run it. Negative controls cover stale state,
malformed input, grant scope, insufficient budget and altered receipts.
