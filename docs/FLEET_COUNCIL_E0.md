# NBG-FLEET-OBS-01 E0 · Research Council Keyholes

**Status:** ISOLATED SYNTHETIC EXPERIMENT / authority NONE. This is a proposal to integrate a research workflow across existing Phi repositories, **not** a working cross-repository execution bridge, physics discovery, scientific measurement, or permission grant.

## Question

Can two matched candidate summaries be equal under a coarse performance Keyhole but separable under a richer, predeclared subgroup Keyhole? Can a deterministic receipt preserve that distinction without silently converting simulation or model-generated discussion into experimental evidence?

The E0 runner is `src/council-e0.mjs`. `npm test` runs the contract tests using the existing Node test glob; no external packages or network are required.

### Frozen simple case

Two synthetic candidates each score **95/100** overall, but each behaves differently on the same groups:

| Candidate | Ordinary | Rare | Overall |
| --- | ---: | ---: | ---: |
| A | 95/95 | 0/5 | 95/100 |
| B | 90/95 | 5/5 | 95/100 |

- K0 observes pooled accuracy and judges the candidates equivalent.
- K1 sees matched subgroup counts and distinguishes the candidates.
- This is an observational-degeneracy witness, *not* proof that NBG is novel, that either model is real, or that LHCb has an anomalous result.
- Metrics are explicitly `SIMULATED`, `PUBLIC_SYNTHETIC`, `authority:NONE`, with producer `synthetic-fixture`. The contract rejects prompts, extra payload fields, claims of physical measurement, and generative participants masquerading as dataset producers.
- Cohort denominators must match. Integer cross-multiplication avoids accidental floating-point equivalence. The canonical deterministic SHA-256 receipt is **integrity/replay metadata only**, not independent provenance authentication.

## Experiment ladder and comparison gate

**E0 (this change):** strict, fully deterministic two-candidate synthetic Keyhole comparison. Tests check the positive witness, nulls, malformed counts, extra payloads, source-tier laundering, and unauthorized execution/share claims. No providers are called.

**E1 (future PRs, not implemented):** frozen, read-only typed `ObservationReceipt` exchange between ThinkTank, PocketBrain and Vessie using test doubles; only then separately approved PhiServe provider invocation. Preserve source SHA, receipt hashes, producer identity, data category and claim tier. Do not infer observational independence from different model names or declared lineage alone.

**E2:** compare an NBG-inspired Keyhole policy against standard stratified evaluation, Bayesian value of information and fixed-sequence baselines on held-out public synthetic tasks. Report usefulness, calibration, false promotions, work cost, load time, RAM/VRAM and any failures. A tie or defeat must be reported plainly.

**E3:** add scoped BrainC provider validation and optional GAIA ideation presentation. Keep symbolic association out of measurement, verdict and physics evidence fields.

**E4:** only after permission, source authenticity, privacy and real hardware acceptance may a PhiShare-like sharing transport be considered. This repository does not identify an implemented `PhiShare` contract.

## Safety / claim firewall

- **Capability is not authority.** Nothing here may dispatch GitHub Actions, run a model, share records, access memory, create PRs, merge or deploy.
- **Agreement is not independent validation.** Multiple LLM answers do not become corroborating measurement.
- **Synthetic success is not physics.** LHCb rare-decay measurements motivate our question about coarse observables; this fixture contains no CERN data and makes no prediction about beauty mesons.
- **Source claims require custody.** A future observational study must pin primary records, treatment of errors/correlations, acceptance criteria and null comparisons before scoring.
- **No autonomy by dashboard.** PhiMada is a read-only display; Agentora's existing actual worker pilot is narrowly scoped and must not be silently generalized.
