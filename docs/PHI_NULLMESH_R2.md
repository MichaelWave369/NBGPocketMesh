# ΦNullMesh R2 — relational path consistency

Research-only continuation of merged R1 (#52). Uses the actual bounded exact Q(i) arithmetic and bridge validators from R1. Graph contains 1–9 declared frames at one boundary site (same id, tick, dimension), 0–36 distinct undirected edges, no self edges, each a validated reversible R1 bridge. Canonical ASCII ordering and edge orientation; reject unregistered endpoints, duplicate edges/frames, malformed flags and authority injection. Paths contain at most 18 hops; no implicit connection across components. Arithmetic output bounds inherited from R1; overflow may refuse even if a larger-domain result exists.

For each connected component choose the lexicographically first frame as root and construct a deterministic breadth-first spanning tree. Store P_v mapping root coordinates to frame v and its inverse, and tree path. Edge T_uv must equal P_v P_u^-1. Check every edge; mismatch yields expected/actual matrix and explicit root-based closed walk with H=P_v^-1 T_uv P_u. If all edges match, any composable walk telescopes to P_end P_start^-1 (assuming products representable); every closed walk is identity. Conversely a failed edge yields nonidentity closed-walk witness. This is an elementary mathematical argument, not a machine-checked proof. Finite tests check implementation behavior. All arithmetic is exact within bounds.

resolve rebuilds/validates the graph and refuses the entire inconsistent registry (even queries in other components). Disconnected queries refuse; isolated frame identity valid. General walk instead evaluates an explicit path in a locally valid graph without requiring global consistency. It returns a separate zero-authority transport record, not a coordinate bridge, including nonidentity loops. Under a consistent change of coordinates at the loop base, holonomy H becomes S H S^-1. This does not establish curvature, physical connection, spacetime, Lorentz invariance or quantum gravity. A nontrivial loop is evidence of a mismatched pure-coordinate declaration OR a property of an explicitly interpreted transport model, not proof of physical curvature. Pairwise invertibility cannot authenticate physical frame correspondence.
