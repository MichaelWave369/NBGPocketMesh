# Relational universe: boundary and topology contract

Research proposal only; E0/E1 routing and inference gates are unchanged. The source of finite algebra/consistency experiments is Altermath; observer experiments live in PhiGenesis.

## Pocket representation
Address (lazy recursive path, not allocation), generator/version, seed, boundary encoding, local rule/algebra/epoch, transform, explicit delta, recovery scheme, provenance. For a restricted XOR grid P[i,j]=r[i] XOR c[j], 2N−1 independent bits determine N² cells; arbitrary N² bits cannot be reconstructed from a perimeter of 4N−4 bits. Account for seed, metadata, deltas and parity overhead. Tensor networks, local automata and hyperbolic representations are candidate backends, not interchangeable proofs of holography.

## Typed membrane
Contract includes source/target domains, state map, operation map, invertibility, declared loss/error, authorization, resource budget, version and receipt. Exact conjugacy requires bijective h and h(f(x))=g(h(x)); incompatible cycle structure prevents such translation. Embedding/projection are distinct and must not be described as reversible. Preserve unknown/unvalidated state. Existing capability router remains fail closed.

## Integrity and growth
Branches provide expansion; cycles provide checks. XOR loop closure detects inconsistency but misses consistent changes (e.g. flipping both corner edges of a grid). Historical anchor and independent receipts needed. Enumerate ambiguous repair options; no silent repair or new rights. Proposed graph rewrites: create bounded child, add authorized compatible link, remove redundant link only if connectivity/integrity tests pass, retire isolated region. Compare fixed/tree/redundant/adaptive growth under equal node/link budgets; measure connectivity, path length, erasure recovery, detection/localization, cost and replay. Finite tests first; no infinite allocation, real routing improvement or physical claim.
